# 2026-10-29 工作日志

## AI 作曲功能重构（compose）
- 问题：原乐器清一色 Tone.Synth 电子音，单调；高级模式只是手动段落编辑器，不符合需求。
- 改动 `public/compose/app.js` + `index.html`：
  - 新增风格化乐器库 makeTimbre/makeBass：钢琴(FM)、电钢Rhodes、失真电吉他、木吉他(拨弦)、萨克斯/小号(AM)、弦乐、管风琴(fat)、合成主音、铺底、古琴拨弦、钟琴；贝斯分合成/无品/爵士低音/摇滚。每个 STYLE 配乐器组合（流行=钢琴+电钢，摇滚=失真电吉他+摇滚贝斯，爵士=萨克斯+爵士低音，古典=钢琴+弦乐等）。
  - 和弦大/小三度改为按音阶推导（`hasMajorThird`），去掉已删除的 mood.bright 依赖。
  - 双模式：基础模式 = AI 读提示词直接生成完整曲（原行为，换乐器）；高级模式 = 四步 AI 领航向导（①选类型 流行/摇滚/爵士/古典等 → ②AI 生成3段不同片段供试听勾选 → ③用户改乐器/移调/密度/小节/鼓 → ④AI 编排成 前奏→主歌→副歌→桥段→尾奏 完整歌，含情感与调性转变）。
  - 混响/延迟每次 makeInstruments 内建，兼容 Tone.Offline 导出 WAV。
- 部署脚本 `scripts/push_via_api.py` 修复：collect_dirty 现在递归展开未跟踪目录，避免漏提交 `public/music/decoders/` 与 `public/vendor/`（之前只提交音乐功能但解码器/库始终未上线）。
- 已通过 GitHub Contents API 推送并触发 Render 部署；线上 `/compose/` 已验证返回新双模式 UI。
- 注意：音频需浏览器用户手势触发，本环境无法试听；建议用户在桌面 Chrome/Edge 实测音色与四步流程。
