适配的主流 3D 软件与格式

本桌宠基于 Three.js（WebGL）渲染，原生支持 glTF/GLB，并通过附加加载器支持 FBX / OBJ。以下为常见 3D 软件与其可导入本桌宠的格式对照：

3D 软件可导出并导入本桌宠的格式说明
Blender（开源）glTF / GLB、FBX、OBJ推荐导出 glTF 2.0（.glb 单文件最方便）
Autodesk MayaFBX、glTF、OBJ用 FBX 或 glTF 导出插件
Autodesk 3ds MaxFBX、glTF、OBJ需安装 glTF / FBX 导出插件
Cinema 4D (C4D)FBX、glTF、OBJ原生支持 FBX / OBJ 导出
ZBrushOBJ雕刻模型常用 OBJ 交换
Sketchfab / MixamoglTF / FBX角色/动画资源可直接下载后导入

提示：动画（骨骼）在 glTF/FBX 中可保留；OBJ 为静态网格，不带动画。若加载失败，请确认模型为上述受支持格式且未损坏。
