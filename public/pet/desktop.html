三步放到桌面

  1. 下载并解压：下载完成后，右键 zip →「全部提取 / 解压到当前文件夹」。请放到一个固定位置（例如 D:\WhaleGirlPet），不要直接在压缩包里双击运行。
  2. 双击 WhaleGirlPet.exe：第一次运行 Windows 可能弹出「已保护你的电脑」，点「更多信息」→「仍要运行」。程序没有购买代码签名，这是正常的未签名提示。
  3. 桌宠出现：透明小鲸鱼会待在桌面右下角并始终置顶，鼠标只在它身上生效，点桌面和别的窗口完全不受影响。右键桌宠开菜单，右下角托盘图标可退出。

使用前要知道

· 整个文件夹要放在一起，不能只把 exe 单独拷到桌面，它依赖同目录的运行库与动画文件。

· 网页版和桌面版的设置不互通：在网页版填过 API Key 的话，要在桌面版「右键 → 桌宠设置」里再填一次。不填也能离线陪聊。

· 右键桌宠 →「桌宠设置」可切换桌面漫游 / 小窗口形态、选显示器、调不透明度、开机自启。

· 「陪工作监测」默认关闭：在右下角托盘右键菜单里开启。开启后只读取最前面窗口的标题、程序名和键鼠空闲时间，不截屏、不读取窗口内容、不联网、不上传、不消耗 API 额度；检测到你开始工作，它会说「本鱼来陪主人工作」、拿出手边的小本子和笔（不戴眼镜，脸和平时一样），一直陪到你结束工作才收起。随时可在托盘关掉。

· 卸载：托盘右键「退出」，然后直接删除整个文件夹即可，不留注册表项。

· 若透明窗口黑屏或闪烁，用命令行启动：WhaleGirlPet.exe --compat。

· 程序不上传你的数据；API Key 只保存在本机，网站服务端不保存也不代付；动画素材全部内置，断网也能玩。

常见问题

为什么下载包接近 200 MB？

桌面版内置了一整套 Chromium 运行时（约 240 MB，压缩后约 100 MB）才能画透明窗口，另外还有 63 MB 的手绘逐帧动画素材（全部内联在页面里，所以离线也能动）。压缩包已排除了自检文件。

「陪工作监测」会看到我的屏幕吗？

不会。它只调用 Windows 的前台窗口信息接口，拿三样东西：窗口标题、程序名、你多久没碰键鼠，用来判断「是不是在工作」。不截图、不录屏、不读取文件内容、不联网，也不需要 API Key。默认关闭，首次开启会先弹一次说明；关掉后程序完全不采样。网页版没有也不可能有这个功能——浏览器不允许网页静默读取用户的桌面状态。

安全吗？能校验文件吗？

这是本站作者自己打包的绿色版，没有第三方安装器、不写注册表、不会自动联网上传你的数据；未签名所以 Windows 会提示一次。下载后可用下面的 SHA-256 校验；解压后文件夹里有 README.txt 说明。

Mac / Linux / 手机能用吗？

桌面版目前只提供 Windows 10/11 64 位。其它系统请直接用网页版，交互与动画完全一致，只是不能悬浮在桌面上。
