📂 本地加密歌曲 → MP3

选择你电脑/手机里「会员下载」的加密歌曲：网易云 .ncm，QQ 音乐 .qmc / .qmc0 / .qmc3 / .qmcflac / .qmcogg / .mflac / .mgg / .bkcmp3 / .bkcflac / .tkm。解密与转码全部在你的浏览器本地完成，文件不会上传任何服务器。

仅用于转换你已合法获取的个人音频做备份。无损格式（flac / m4a）可「下载原格式」或「转 MP3」（转码在本地浏览器进行，较长歌曲稍慢，手机可能吃力）。
